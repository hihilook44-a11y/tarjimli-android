# ترجملي مباشر — نسخة أندرويد تجريبية

نسخة مبنية على مشروع [LiveSub](https://github.com/R-Dilipkumar/LiveSub-Offline-Translator) برخصة MIT، مع إعداد افتراضي للتركية إلى العربية وWhisper Base؛ يُحفظ إشعار الترخيص في LICENSE. تعرض نافذة عائمة، وتحتاج أندرويد 10 أو أحدث وصلاحية التقاط الصوت والعرض فوق التطبيقات.

هذه نسخة تجريبية ولم تُختبر بعد على هاتفك أو مع الحلقة. قد تمنع بعض الفيديوهات أو التطبيقات التقاط الصوت، وقد تتأخر الترجمة وتخطئ. تعمل عبر صوت الهاتف الملتقط، وليست ترجمة متزامنة تمامًا مع كل مشغل. لا تعمل على iPhone.

## الإعداد
1. نزّل ملف APK من Releases وثبّته. سيعرض أندرويد تحذيرًا لأن النسخة موقعة بمفتاح اختبار.
2. افتح Models ونزّل Whisper Base (نحو 198 ميجابايت) وحزم اللغتين التركية والعربية (نحو 30 ميجابايت لكل لغة). التنزيل يحتاج إنترنت ومساحة كافية.
3. على شاشة Translate تأكد من Turkish → Arabic وPhone audio، ثم اضغط Start واسمح بالعرض فوق التطبيقات وبالتقاط الصوت عندما يطلب النظام.
4. شغّل الحلقة في المتصفح. نافذة الترجمة العائمة قابلة للتحريك.

المعالجة مستندة إلى Sherpa-ONNX/Whisper وGoogle ML Kit، وتشغيلها محلي بعد تنزيل النماذج وفق تصميم المشروع الأصلي؛ تراخيص ومصادر النماذج في README الأصلي. لا تضمن هذه النسخة قابلية التقاط كل المحتوى.
